# 频控、授权与安全

## 频控
- 顺序执行，同一时刻只处理一个站点；同域两次提交之间停顿（用 waitFor 或短暂 snapshot 检查代替硬等待）。
- 一个批次跑不完就释放租约下次继续，不要赶进度。

## 授权边界
- 你被授权执行：浏览、注册（用 cloud-mail 邮箱）、登录、填表、提交外链表单、读取公开页面。
- 你不被授权：付费/购买（→ skipped）、修改对方站点其他内容、处理支付信息、破解或绕过验证码。
- 遇到付款页立即停：回写 skipped（付费）或 manual_required（需要人决策）。

## 凭据与隐私
- 站点账号密码由浏览器持久 profile 记住，你不读取、不回写、不出现在 evidence 里。
- mailbox 地址是一次性的，可以出现在 evidence 里。
