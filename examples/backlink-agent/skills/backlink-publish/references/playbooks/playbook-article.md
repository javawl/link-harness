# 内容站 / Web2.0 投稿（category: 内容站）

需要写文章的站点（Medium 类、开发者社区、博客平台）。

## 流程
1. 注册 + 邮箱验证 + 登录。
2. 写一篇 400-800 字的文章：主题与目标网站强相关，锚文本**自然地**嵌在正文里（一篇只放 1 个目标链接，多了像垃圾）。
3. 文章结构：标题 + 2-3 段正文 + 结论；语言跟随站点主流语言。
4. 发布后打开文章公开 URL 核验链接 → live；显示"审核中" → submitted。

## 边界
- 专栏需要申请/原创声明/实名 → manual_required。
- 平台明禁外链 → skipped。
