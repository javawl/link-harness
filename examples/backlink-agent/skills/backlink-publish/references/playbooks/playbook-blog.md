# 博客评论（category: 博客）

在相关博客文章下留评论形成外链：表单有 Website 字段时填填写者主页 URL，没有时把链接嵌进评论正文。

## 流程
1. 找到与目标网站主题相关的**近期文章**（从 sourceUrl 或站内最新列表挑，不碰多年前的旧文）。
2. 勘察评论表单，**按形态选带链方式**：
   - 有 姓名/邮箱/网站(Website)/评论内容 → 邮箱用一次性邮箱；Website 字段填 anchors 里的 targetUrl；评论正文**不带链接**。
   - 只有评论正文一个输入框（Wix 类组件）→ 走下面的**正文嵌链**流程。
3. 评论内容必须**针对文章内容**写 2-3 句真实观点——泛泛的"好文章"大概率被当垃圾删掉，宁可跳过也不要水评。
4. 提交后看回显：立即可见 → 核验 live；显示"待审核" → submitted。

## 正文嵌链（无 Website 字段的评论区）

1. **提交前先拿到"本站接受正文链接"的证据**，三者居一：
   - 评论区已有上线评论的正文带**可点击**链接（aria 快照里 `role:link`，最强证据）；
   - 评论框是富文本编辑器，工具栏有链接按钮；
   - 表单附近有 "HTML allowed" / `<a href="">` 类格式提示。
   一个都没有 → 回写 `skipped`（skipReason："评论区无 Website 字段且无正文链接先例，无途径携带目标链接"），**不发试探性评论**——一次最终提交的铁律下发出去的无链评论就是纯水评。
2. 写 2-3 句观点，**一段评论只嵌 1 个链接**（多了像垃圾，与内容站剧本对称）；锚文本用 anchors 第一个 active 项的 anchorText，必须融进句子读得通，不是孤零零一段链接。
3. 输入方式按第 1 步的证据来：富文本框 → 先输完整观点句，选中锚文本片段，点工具栏链接按钮填 targetUrl（语义寻址定位工具栏按钮）；纯文本框但有先例 → 正文里写 `<a href="targetUrl">anchorText</a>`；**裸链 targetUrl 只在站内已有裸链被自动转为链接的先例时才用**。
4. **核验口径比普通评论严**：aria 快照里该评论正文出现 `role:link` 且名称含 anchorText 才算链接真的嵌上了。回显若是被转义的 `<a href=…>` 纯文本（能看到 targetUrl 字符串但没渲染成链接）→ 链接未生效，回写 `failed + manual_required`（failureReason："正文 HTML 被转义，链接未生效，需人工编辑评论"），**绝不自动重发第二条**。

## 边界
- 评论关闭/需登录（含 Wix "Log in to publish as a member"）/Disqus 之类第三方登录 → 走单条目循环第 5 步登录决策树；仍过不去 → manual_required 或 skipped（视情况）。
- 一个博客只评论一次；不要连续刷同一站点多篇文章。
