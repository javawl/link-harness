# 博客评论（category: 博客）

在相关博客文章下留评论，评论区填写者主页 URL 形成外链。

## 流程
1. 找到与目标网站主题相关的**近期文章**（从 sourceUrl 或站内最新列表挑，不碰多年前的旧文）。
2. 勘察评论表单：姓名/邮箱/网站(Website)/评论内容。
3. 邮箱用一次性邮箱；Website 字段填 anchors 里的 targetUrl。
4. 评论内容必须**针对文章内容**写 2-3 句真实观点——泛泛的"好文章"大概率被当垃圾删掉，宁可跳过也不要水评。
5. 提交后看回显：立即可见 → 核验 live；显示"待审核" → submitted。

## 边界
- 评论关闭/需登录/Disqus 之类第三方登录 → manual_required 或 skipped（视情况）。
- 一个博客只评论一次；不要连续刷同一站点多篇文章。
