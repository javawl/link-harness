# Agent Note: 发布检查点与网站默认资料

Status: implemented

[English](2026-09-07-backlinks-publication-checkpoints.md) | 中文

## Problem

前台整批结果返回过晚，无法保护取消或进程重启时尚未完成的提交。已保存的 skipped/failed 结果还必须阻止后续浏览器输入。任意页面上的目标 href 不能证明外链来自所分配来源；手选之前去重可能静默移除所选条目。把每次局部预算停止都当成整批失败，会留下无关的待处理工作。

## Decision

外链消费方写入仅日志可见的 `backlinks/attempt` 记录，并在把已认领条目交给模型前等待会话刷写。父日志独立于最终工具结果保存每个已接纳条目。取消和压缩保留排除记录；已尝试但仍待处理的条目需要核对。检查点失败会阻止子任务首次请求。运行时不变量拒绝同一会话重复接纳条目。这扩展了[请求预算](2026-09-05-backlinks-request-budgets.zh.md)的持久结果防护，其请求计量和原生子任务所有权仍然有效。

条目结果保存后禁止继续浏览器输入或导航。页面关闭同时取决于提交确定性和已保存状态。live 与 submitted 都要求已声明最终提交；已有外链记为 skipped。live URL 必须使用所分配来源或提交地址的主机，仅忽略开头的 www，且不能使用推广站或目标地址的主机。提供方仍核验真实 href。手选先于可执行来源去重，但整个批次中已发布的来源仍被排除。

Supermanager 优先使用显式锚点，否则使用已保存的网站名称和 siteUrl 作为默认文本和 URL，不伪造后台锚点 id，也不写入网站。这替代了[页面保留与预检](2026-09-07-backlinks-retained-pages.zh.md)中必须另建锚点的设置要求。无效显式锚点仍报错；缺少可用默认资料时，仍在开页、认领和请求模型前停止。

原生驱动用 budget-exhausted 表示单次运行预算耗尽。publisher 核对局部预算和输出 token 停止后，继续其他条目。已尝试但没有已保存结果的来源，以及核对失败的条目，都排除后续派发并列入 unresolvedItemIds，不改写后台状态。未知提交保留页面。remaining 为零且 stoppedReason 为空时，本次选择执行结束，未决项单列交人工核对。终态模型错误、检查点失败、租约丢失和后台鉴权失败停止新派发。请求时预算检查涵盖重试，但不覆盖提供方的终态错误。

## Alternatives considered

**依赖最终结果元数据。** 取消会替换工具结果，崩溃可能完全阻止结果产生。请求前检查点会在结果未知期间保存已接纳条目。

**用任意匹配链接推断成功。** 推广站首页的自链接也满足 href 相等，但不代表所分配来源产生了外链。来源归属和已声明提交是各自独立的必要事实。

**要求每个网站另建锚点记录。** 用户确认的网站资料已经提供默认名称和网址。复用权威资料避免重复设置；根据网页文案编造锚文本或静默替换无效显式锚点仍不允许。

**任何子任务预算耗尽或未决结果都停整批。** 单项限制或缺失结果不能证明另一个来源不可用。持久尝试排除记录防止重发，无需阻塞无关来源。后台 skipped 仅用于明确的跳过结果；unresolvedItemIds 单独保留不确定性。全局资源和存储错误仍触发停止。

## Consequences

检查点增加存储操作，不增加模型上下文或模型请求。正确性依赖已配置的持久化后端兑现会话刷写；纯内存组合无法跨进程恢复。既有结果元数据仍可读取，但早期没有尝试记录的中断调用仍须核对后台和子会话日志。精确主机匹配不推断无关的重定向域；已授权发布域应录入来源资料。

公开接口回归覆盖取消伴随后台核对失败、检查点失败、终态输入拒绝、无关 live URL、手选、局部预算接续与额度错误保留。组装发布场景使用真实 Supermanager 解析器、Chrome、原生子任务和持久父会话尝试记录。测试不证明生产 token 节省、匿名链接可访问性或第三方接收率。
