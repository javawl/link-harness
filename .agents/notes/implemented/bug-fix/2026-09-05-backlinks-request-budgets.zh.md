# Agent Note: 外链请求与原生子任务预算

Status: implemented

[English](2026-09-05-backlinks-request-budgets.md) | 中文

## Problem

长时间外链批次会把完整批次记录和子任务历史反复发送给模型。主任务轮询和租约心跳虽不执行发布，却仍各自消耗一次模型请求。子任务可能持续调试同一站点而不产出条目结果；按步骤替换用量又会隐藏与重试处于同一步骤的失败尝试。

## Decision

外链组合用一次前台 `backlink_publish` 调用处理已确认范围。队列最多补满三个并发位，同一目标主机串行，复用原生子任务启动、结果及释放机制。一个租约覆盖所选来源，现有定时器续租不消耗模型轮次。认领或启动付费工作前先预留页面；子任务作用域执行器强制页面与条目归属，核对结果后才关闭页面及释放租约。固定纪律通过 persona 提供，任务提示词只含条目资料。Bash 仍用于网站核对及素材，其用途指引不是安全边界。通用委派工具为独立调用方保留有数量上限的提示词数组 API。

Web 会话在宿主组合之后加载预设。部署通过 `agent-presets.overrides` 为 standard、code 和 cordis 设置发布 persona、压缩与工具排除项，使用 Include 加载器现有补丁机制。发布会话不加载编码指令、默认文件系统技能发现、文件系统工具或独立委派控制。Web 回归创建并恢复三种预设，检查 persona 与工具可见性。既有日志内容仍是历史上下文；新会话可避免继续携带旧编码指令。

backlinks 工具默认返回计数，按需返回有界的完整条目页。代码选择待发布或可重试条目，按来源去重，排除已发布来源，并在认领前检查最新详情。认领返回 id 与租约元数据。已认领 id 记录在结果元数据中，在该 agent 会话及其重放中都被排除。再次尝试须先后台复核并新建会话。排查仍可显式读取完整详情。

原生 spawn 与 fork 提供方校验可选运行预算，并通过现有共享驱动器在子任务发布前安装。限制覆盖报告的请求 token（含缓存与重试）、步骤、经过时间及相同工具失败。检查位于后续模型工作之前，让已派发工具结束。预算耗尽记录为持久错误，并提供父任务诊断。publisher 在补写结果前检查后台记录：尚未声明最终提交的中断可以重试；已派发或输入不确定的提交保持待人工。配置预算后拒绝可续接启动，因为其激活所有权不同。

token-meter 投影把终态 finish 分片分隔的流计为不同尝试，包括同一步骤内的重试。同次尝试的重复用量样本与最终消息用量相互替换。提供方 response id 不是唯一请求标识。提供方异常值完整保留以供审计。normal 重试策略默认允许一次空响应重试，同时受到总重试上限约束。

共享浏览器比子任务存活更久，因此请求预算不能约束留存页面的内存。Playwright 提供方在每次请求开页前预留容量，覆盖并发调用；超限时拒绝请求，不关闭已有工作。发布流程在确认 live/submitted/skipped 已回写后关闭页面，容量不足时停止新工作；未知提交及待人工页面保持原状。导航就绪条件和超时独立于定位器等待配置，快照使用配置的定位器超时。[真实 Chrome 快照](../../../../examples/backlink-agent/tests/browser-capacity.snapshot.ts)验证容量、已有工作保留、关页释放容量、图片仍在加载时的 DOM 就绪及快照期限，运行需要已安装 Chrome。

原始按键与坐标输入使用提供方拥有的等待期限。Playwright 不提供这些调用的无损取消，因此到期或取消会报告 `BROWSER_ACTION_UNCERTAIN`，并锁定该实际页面交人工核验。提供方保留输入 Promise 直到结束，关闭浏览器时等待所有在途输入清理完成。迟到的完成不会解除自动操作锁定，显式关页才释放页面。其他标签页仍可用。真实 Chrome 快照覆盖忙碌按键处理器、拒绝重复输入及另一站点仍可用。

发布技能在范围与模式确认后、首次认领前激活现有 Goal。目标覆盖全部所选工作，而非一页认领；Goal 驱动器在压缩后保留目标，并在模型普通停止后继续。工具读取和认领携带相同的 `scope`（`pending`、`retryable` 或 `all`），因此仅待发布任务在分页前就排除可重试失败。控制台按批次 id 降序排列摘要，因为复制批次可能沿用更早的计划时间。[范围快照](../../../../examples/backlink-agent/tests/selection.snapshot.ts)经 Loader 检查范围耗尽和控制台排序；它不证明真实模型遵守指令。

原生子任务从父任务最近一次已记录请求继承 provider/model，没有请求时使用创建配置，显式子任务覆盖优先。这使 [Web 模型选择](../feature/2026-08-07-default-model-follows-the-picker.zh.md)与后续委派工作保持一致，不修改已运行子任务或重放历史。

模型或基础设施错误停止新派发，在释放租约前等待在途工作结束。局部预算和输出 token 停止遵循[发布检查点](2026-09-07-backlinks-publication-checkpoints.zh.md)：核对本条、保留未知提交并继续无关工作。原生错误诊断暴露 QUOTA 等有界代码，原始提供方载荷保留在子日志中。每次浏览器预留后重新检查派发条件。已尝试的所选来源仍待处理且没有发布记录时，须先核对。

[发布快照](../../../../examples/backlink-agent/tests/publisher.snapshot.ts)通过 Loader 和原生驱动器覆盖模型选择、额度停派和之前未回写的尝试。提供方失败会使后台未启动条目保持待处理，核对过程不再次提交网站。

[保留页面决策](2026-09-07-backlinks-retained-pages.zh.md)扩展此策略：允许关闭总页数上限，并回收提交前已保存失败的页面。原生执行预算及不确定输入保留要求继续有效。

## Alternatives considered

**每次模型错误后继续执行。** 额度或鉴权失败可能影响整条队列，反复启动子任务会消耗请求，并把未访问的网站标成失败。异常终止后停派可保留工作；正常回写的网站失败仍允许继续。

**把提供方原始错误复制到父任务结果。** 原始载荷可能包含凭据或请求数据。有界代码标明错误类别，详细证据保留在子任务日志中。

**只继承创建时的模型配置。** 动态模型选择会改变请求路由，却不会修改这些配置。已记录请求才是父任务实际使用模型的持久证据。

- 只写在提示词中的预算无法阻止下一次付费请求，也无法强制工具失败上限。
- 重写子任务生命周期会重复原生委派机制。发布队列只负责批次选择、页面权限、结果核验及并发准入；原生运行负责子任务执行与清理。
- 达到 token 阈值时中断活跃工具，可能发生在站点已接受提交、但结果尚未记录之间。
- 把缓存输入当成免费会掩盖重复请求量，也无法确定网关配额或计费规则。
- 缺少能够确定原因的原始网关响应时，清零异常输出会丢弃证据。
- 自动淘汰旧页或在子任务结束时关闭所有页可能丢失未知提交或人工接续状态。拒绝超额开页可保留这些页面，并要求显式清理已完成工作。

## Consequences

协调等待不产生 LLM（大语言模型）调用。小页与子任务工具过滤减少重复上下文。预算是停止阈值：单次请求可以超出，提供方未报告的用量及直接压缩调用不计入，经过时间在请求之间检查。原生定位器超时限制元素等待；中断的原始输入保留未知结果及页面，等待人工核验。[并发快照](../../../../examples/backlink-agent/tests/parallel.snapshot.ts)启动三个原生子任务，要求三者均已启动才能执行首步，并检查已记录的提示词与有序结果。这些限制需要结合发布结果校准，并不代表已经测得生产节省比例。

页面容量约束请求造成的增长，不是进程 RSS 限制；恢复标签页及站点自行弹窗会计数，但不被强制关闭。资源监督还须检查浏览器内存和系统压力，任务仍有进展不代表宿主健康。监督运行状态应放在持久存储，不能放在重启会清空的临时目录。

[发布记录守卫](../../implemented/feature/2026-09-01-backlinks-duplicate-publish-guard.zh.md)仍需目标站核验补充。[子任务纪律传递渠道](2026-09-03-backlinks-discipline-delivery-channel.zh.md)仍是必需的：缩小提示词也保留延迟加载、链接格式、核验和注册规则。[用量投影决策](../../implemented/architecture/2026-07-29-projected-token-usage-and-request-context.zh.md)继续保留持久总量和近似占用率。这些记录得到部分扩展，保持活跃。

真实装配的无密钥[预算场景](../../../../examples/backlink-agent/tests/budget.snapshot.ts)检查小批次结果与原生预算停止。[publisher 场景](../../../../examples/backlink-agent/tests/publisher.snapshot.ts)覆盖真实 Chrome、普通及嵌套 frame 表单、批量填写、重新访问公开页后的 href 核验，以及仅保留一份技能正文。定向原生测试检查滚动补位、同主机串行、跨页和跨条目拒绝、容量准入、取消与回写响应丢失。skill 工具仅省略当前会话中仍可见且未变化的正文；压缩或技能修改后允许重载。不从这些检查推断生产发布率或付费模型节省量。
