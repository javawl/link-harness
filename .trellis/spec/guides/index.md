# 可复用工程指南

这些文件只包含可跨项目复用的工程原则。它们不描述任何具体仓库的架构，也不引用源仓库私有路径。

| 指南 | 目的 |
|---|---|
| [工程规则](./engineering-rules.md) | 权威来源、生成文件、状态边界、改动范围和护栏升级 |
| [证据标准](./evidence-standards.md) | 正确性、性能、可复现性、缺失值和敏感信息边界 |
| [调试直觉](./debugging-instincts.md) | 生成漂移、外部依赖、状态冲突、性能证据和脏工作区处理 |

具体架构、命令、测试和事故规则必须写在当前仓库的 `../project/` 中，并引用当前仓库真实存在的源码、测试或权威文档。单次需求结论不得直接提升为通用规则。
